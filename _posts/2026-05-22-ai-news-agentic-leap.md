## Google's Gemini 3.5 Flash Powers Search Revolution

Google announced its Search bar is now fully powered by **Gemini 3.5 Flash**, delivering custom AI-summarized pages instead of link lists. Users get follow-up questions, image/video queries, and "information agents" for background tasks. Described as the biggest Search overhaul in 25+ years.

Simultaneously, **Gemma 4** open models launched (Apache 2.0) for advanced reasoning and agentic workflows. New Antigravity CLI and agent integrations signal proactive AI everywhere.

[Source: Google AI Blog](https://ai.google/)

## OpenAI Launches Codex Autonomous Coding Agent

OpenAI unveiled **Codex**, a brand-new autonomous coding agent, alongside GPT-5.3-Codex-Spark for lightning-fast real-time coding (128k context). This accelerates the coding agent wave reshaping software engineering.

[Source: OpenAI announcements via recent coverage](https://openai.com/)

## Open-Source Momentum from Nvidia, Cohere & Indie Devs

- **Nvidia Nemotron 3 Super**: Open weights released with full training docs and research materials.
- **Cohere Command A+**: 218B MoE model open-sourced – excels in agentic tasks, runs efficiently on 2x H100 GPUs.
- Emerging tools like **Paperclip** (multi-agent coordination) and **Datasette Agent** highlight small-dev innovation in open coding frameworks.

Alteryx also launched Agent Studio for turning business workflows into autonomous agents.
